# 🔐 Cyber-Dashboard: Pro - Criptografía Clásica

Este proyecto implementa un sistema web de cifrado y descifrado basado en los algoritmos César y Atbash, integrando un motor de criptoanálisis estadístico.

## 🛡️ Documentación Segura e Integridad
Para cumplir con los estándares de ciberseguridad y la restricción de "no impresiones", se ha implementado un esquema de **Integridad Digital**:

1. **Disponibilidad:** El reporte técnico completo reside en este repositorio digital, garantizando acceso seguro vía HTTPS.
2. **Firma de Integridad (SHA-256):** Para asegurar que el documento es original y no ha sido modificado, se proporciona su Hash:
   - **Archivo:** Primeros pasos cifrando.pdf
   - **Hash SHA-256:** a74a1aac8b2941575dd5e727c7d837282bb05f4d677c3e90802a78c19a611a62
3. **No Repudio:** El uso de GitHub permite la trazabilidad completa del desarrollo mediante el historial de cambios.
